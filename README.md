# notae

你指着一段看不懂的材料，说哪儿不懂。它按你的思维习惯重新组织语言讲一遍，
然后把**引用坐标**、**困住你的那段摘录**、**解读**写成一份笔记。

> `notae` 是拉丁语 `nota` 的复数——中世纪抄书人写在文本旁的解释性标记。

```bash
notae explain https://arxiv.org/abs/1706.03762 --confused "为什么 QK^T 要除以 sqrt(d_k)"
notae recall attention-scaling      # 三个月后回看：解读 + 当时的困惑 + 当时那段原文
```

## 这不是什么

- **不存原文。** 解读时把原文读进上下文，落盘只留引用 + 摘录 + 笔记。
  页边注不包含整本书的副本。
- **不是笔记应用。** 笔记是副产品，核心价值是「按个人学习习惯重讲一遍」这个动作。
- **不是 RAG 阅读器。** 不做"把你的库全读一遍然后回答问题"，是你指着哪儿它讲哪儿。

## 设计取向

- **本地优先。** 笔记是纯 Markdown + frontmatter，存在你自己的磁盘上，Obsidian 直接可读。
  删掉本工具，笔记仍然是笔记。
- **笔记自洽。** 源链接失效、文件移动、原文被改，笔记依然完整可读——因为摘录就在笔记里。
- **引用免费，理解付费。** 只有「重讲」那一步调用大模型，其余全部用代码完成。
